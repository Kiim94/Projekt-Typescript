# Projektuppgift - Kursöversikt + Ramschema

## Publicerad webbplats
[Här finns applikationen](https://kiim94.github.io/Projekt-Typescript)

En webbapplikation där man kan se kursutbud från 2023 samt välja vilka kurser man vill spara i ett eget ramschema.

## Funktioner
- Visa hela kursutbudet
- Söka efter kurser
- Filtera kurser efter ämne
- Sortera kursinformation i stigande eller fallande ordning
- Lägga till kurser i ramschemat
- Ta bort kurser från ramschemat
- Beräkning av totalt antal högskolepoäng
- Beräkning av antal kurser i ramschema

## Tekniker som använts

- Angular ramverk
- TypeScript
- SCSS
- Angular Signals
- Angular Routing

## Installation
Klona projektet:
```
git clone https://github.com/Kiim94/Projekt-Typescript.git
```
Installera beroenden:
```
npm install
```
Starta utvecklingsserver:
```
ng serve
```
